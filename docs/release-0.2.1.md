# Django Nadein Board 0.2.1

This packaging and documentation release adds the MIT license, copyright 2026 Igor Nadein.

- Include LICENSE in the repository, source distribution and wheel.
- Declare the MIT license in Python package metadata.
- Update the four-language README and architecture documentation with license links.
- Retain the task-board features and bundled React interface from 0.2.0.

Requires Python 3.11+ and Django 5.2. Install the attached wheel or the tagged source:

```bash
python -m pip install "git+https://github.com/IgorNadein/django-nadein-board.git@v0.2.1"
```

See the [integration guide](https://github.com/IgorNadein/django-nadein-board/blob/v0.2.1/docs/integration.md) for setup. The package is not published on PyPI.
