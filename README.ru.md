# Django Nadein Board

Самостоятельная доска задач для Django со встроенным React-интерфейсом, выделенная из EUSRR. Версия 0.1.0 переносит ядро доски; это не полная копия всех возможностей портала.

## Возможности

- Несколько досок, доступ создателю, выбранным участникам или всем авторизованным пользователям.
- Колонки, подколонки, дорожки, перенос карточек, срочность, сроки, исполнители и метки.
- Чек-листы, самостоятельные комментарии, загрузка и защищённое скачивание файлов.
- Исходные компоненты карточек и логика раскладки EUSRR, адаптированные к отдельному интерфейсу.
- Работа с `AUTH_USER_MODEL`, сессионной авторизацией и CSRF-защитой Django.

Next.js-сервер, Redis, Celery, мессенджер и модуль уведомлений не нужны. Собранный фронтенд входит в Python-пакет; Node нужен только для его изменения.

## Запуск демонстрации

Python 3.11 или новее:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python manage.py migrate
python manage.py seed_board_demo
python manage.py runserver 127.0.0.1:8765
```


Откройте http://127.0.0.1:8765/board/ — логин `demo`, пароль `demo-board-local`. Это локальные демонстрационные настройки. Данные полностью искусственные, база и файлы EUSRR не копируются.

## Встраивание

Установите пакет из репозитория (на PyPI он ещё не опубликован), добавьте `rest_framework` и `nadein_board` в `INSTALLED_APPS`, подключите `path("board/", include("nadein_board.urls"))`, выполните миграции и `collectstatic`. Используются вход и пользователи вашего Django-проекта. Хранилище вложений должно оставаться непубличным: скачивание проходит через API с проверкой доступа.

[Подробная интеграция, API и настройка доступа](docs/integration.md).

## Границы версии

Пока не перенесены автоматизации, группы и закрепление досок, история действий, обновления в реальном времени и связи с корпоративными объектами. Управление участниками и архивирование доступны через API. Карточки отображаются сначала по срочности, затем по позиции — как в исходной доске. Интерфейс пока на русском языке.

[Что взято из EUSRR и что изменено](docs/extraction.md). Исходный EUSRR не изменён. Лицензия на выделенный код пока не выбрана.

## Проверки

`python manage.py test tests` — backend; `cd frontend && npm ci && npm run build && npm test` — сборка TypeScript и тесты раскладки.

Добавлены исходные механики: панорамирование колёсиком, прокрутка мобильных колонок, сворачивание колонок и дорожек, быстрое создание с выбором срочности, перестановка колонок, кадрирование аватара и обложки карточек из файла, чек-листа или комментария. Участники теперь задаются в настройках доски по ID пользователей Django.
